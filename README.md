# ⚡ DebugLab — Neo-Brutalist Developer Portfolio

> **Mohammed (StackOdyssey)** — Full-Stack Developer & Digital Craftsman  
> Studying at **ISTA (Développement Digital)** & **FreeCodeCamp** • Certified in **Cisco Switching & IP**, **ALX Africa Front-End**, and **C++**.

An interactive, high-voltage **Neo-Brutalist Portfolio** built in **React 19 + Tailwind CSS + Lucide Icons + Web Audio API**.

---

## 🚀 Key Features

- **🎨 Neo-Brutalism Design System**: High-contrast borders, offset hard shadows (`4px 4px 0px #000`), tactile button presses, rotated badges, and retro continuous marquee banners.
- **🌈 4 Dynamic Brutalist Themes**: 
  - `Neo-Volt` (Electric Yellow)
  - `Cyberpunk Dark` (Acid Lime & Dark Canvas)
  - `Candy Brutal` (Bubblegum & Mint)
  - `Matrix Terminal` (Hacker Green)
- **🛠️ Cisco IPv4 Subnet & CIDR Inspector**: Interactive network engineering calculator with bitwise subnet calculations, usable host ranges, and 32-bit binary octet breakdowns.
- **💻 Interactive CLI Terminal Sandbox**: Functional terminal emulator supporting `help`, `about`, `skills`, `certs`, `projects`, `matrix`, `ipcalc`, `contact`, and keyboard history navigation.
- **🛡️ Verified Credentials Hub**: Verifiable credential cards for Cisco Systems, ALX Africa, C++ Foundations, ISTA Morocco, and FreeCodeCamp.
- **📂 Featured Projects & Case Studies**: Showcasing repositories from [@StackOdyssey](https://github.com/StackOdyssey) and full-stack enterprise case studies.
- **🔊 Web Audio API Retro Synthesizer**: Native in-browser click and bleep synthesis with instant mute toggle.
- **⚡ Command Menu**: `Ctrl+K` palette for quick navigation and actions.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS (Neo-Brutalist custom config)
- **Icons**: Lucide React + Custom SVGs
- **Audio**: Web Audio API (zero external assets)
- **Effects**: Canvas Confetti

---

## 🏃 Getting Started Locally

```bash
# Clone repository
git clone git@github.com:StackOdyssey/DebugLab.git

# Install dependencies
npm install

# Run development server with Hot Module Replacement
npm run dev

# Build production bundle
npm run build
```
